# DeepGuard AI Deepfake Model

This folder contains the Deepfake AI model training, validation, and inference scripts.

## Project Structure

- `src/model.py`: Neural network model structure.
- `src/inference.py`: Class to execute deepfake detection inference on images.
- `models/`: Destination folder to store trained model weights/checkpoints.

## Setup

1. Create a python virtual environment and activate it.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
