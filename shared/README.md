# DeepGuard AI Shared Definitions

This directory contains definitions, schemas, and constants that are shared across all DeepGuard platforms:
- Web React application (`/web`)
- Native Android app (`/android`)
- FastAPI backend (`/backend`)
- AI model workspace (`/ai`)

## Directory Structure

- `types.ts`: TypeScript interface definitions for API responses and payload contracts.
- `schemas/`: JSON schemas validating API payload contracts across platforms.
- `constants.ts`: Shared configuration constants.
